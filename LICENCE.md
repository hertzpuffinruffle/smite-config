## 🧩 About

**Smite Config** is a comprehensive overlay and configuration tool for Smite featuring build optimizer, stats tracker, hotkey manager, profile switcher, and in-game overlay menu.

Based on popular tools like **Smite Overlay**, **Smite Config Manager**, and **Smite Stats Tracker**.

## ✨ Features

### 🎮 Core Features
- Overlay Menu — in-game config panel for quick adjustments
- Build Optimizer — auto-select optimal items for your god
- Stats Tracker — real-time K/D/A and gold tracking
- Hotkey Manager — customizable hotkeys for quick actions
- Profile Switcher — save and load multiple configuration profiles

### 🎨 Cosmetics & Unlocks
- Skin Preview — view any skin in the overlay
- Custom UI Themes — change overlay colors and styles
- Voice Pack Switcher — change announcer packs on the fly

### 🏋️ Practice & Training

- Cooldown Tracker — track ability cooldowns for enemy gods
- Damage Calculator — estimate combo damage
